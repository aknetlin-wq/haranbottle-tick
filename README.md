# haranbottle-tick

하란보틀 쇼핑몰을 10분마다 한 번 깨우는 예약 실행입니다.
`https://www.haranbottle.com/order/hb_tg.php?tick=1` 을 부르면 쇼핑몰이 새 주문·문의 알림을 확인하고(있을 때만 텔레그램으로 보냄), 텔레그램에서 누른 단추를 가져와 처리합니다.

- `tick.yml`: 10분마다 위 주소를 부름(깃허브가 바쁘면 몇 분 늦을 수 있음)
- `keepalive.yml`: 60일 무변화로 예약이 멈추지 않게 한 달에 한 번 기록을 남김
- 비밀번호·열쇠 없음. 멈추려면 저장소 Actions 에서 tick 을 끄거나 저장소를 지우면 됨.
